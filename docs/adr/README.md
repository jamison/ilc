# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records documenting significant technical decisions in the ILC project.

## Naming Convention

Files are named: `ADR_NNNN_Short_Description.md`

- `NNNN` is a zero-padded sequence number
- `Short_Description` uses underscores, Title Case

## Status Values

- **Proposed**: Under discussion
- **Accepted**: Approved and active
- **Deprecated**: Superseded by another ADR
- **Rejected**: Considered but not adopted
