# ILC Action Signing Keys

ILC uses more than one kind of key. The root identity key establishes an
`AgentID`; an action-signing hotkey signs day-to-day value-action and graph
submission payloads. Losing or rotating a hotkey does not change the `AgentID`.

## Root Key vs. Hotkey

The root identity key is the ML-DSA-65 root material used by the AgentID lineage
defined by CDL-042, CDL-069, and CDL-090. It is not generated by the hotkey CLI.
Treat root material as long-term identity custody.

The hotkey generated by `ilc agent keygen` is a local Ed25519 private key for
action signing. It is intended for operational use by an agent process or
operator workflow. It is not a root AgentID key, not a Genesis custody key, not a
Shamir recovery share, and not a validator certificate key.

## Generate a Hotkey

Run:

```bash
ilc agent keygen
```

By default, the CLI writes a fresh Ed25519 PKCS8 PEM file under:

```text
~/.ilc/keys/<fingerprint>.pem
```

To choose a location explicitly:

```bash
ilc agent keygen --output /path/to/agent-hotkey.pem
```

The command prints machine-readable JSON containing a `file://` URI and public
metadata. The private key bytes are never printed.

## Fingerprint

The hotkey fingerprint is:

```text
sha256(raw_ed25519_pubkey_bytes_32)
```

It is computed over the raw 32-byte Ed25519 public key, not over DER or PEM
encoding. This is the same fingerprint convention used by signed graph
submission records.

## Using the Key

`LocalEd25519SigningProvider` loads the key from a local `file://` URI. The URI
format is:

```text
file:///absolute/path/to/agent-hotkey.pem
```

The provider currently signs ILC transfer action envelopes. The `--signing-key`
flag for graph submission is added by `GAP-GRAPH-SIGN-00`, not by this phase.

## Custody Rules

Keep hotkey files out of version control and transcripts. The CLI writes files
with `0600` permissions so only the local owner can read them. Do not paste the
PEM into chat, logs, issue trackers, shell history, or graph records.

If a hotkey is lost, there is no recovery mechanism for that key. Generate a new
hotkey and update the local agent configuration or future signer-binding record.
The root `AgentID` is unaffected by hotkey loss or rotation.

## Non-Claims

This page does not define secp256k1, HSM, TEE, or external wallet providers.
Those provider families require later authorization. This page also does not
activate transfers, withdrawals, public write paths, or any production guard.
