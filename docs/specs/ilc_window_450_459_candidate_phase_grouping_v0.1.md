# ILC Window 450-459: Candidate Phase Grouping

Author: GPT-5 Codex (planning draft)
Date: 2026-03-19
Baseline assumption: Window 441-449 closes cleanly with `CDL-051` resolved and the current
constitutional carry-forward wording around `CDL-050` still frozen.

Planning note: this is a candidate grouping only. It does not amend the active `441-449`
baseline and does not authorize post-`449` execution by itself.

---

## 1. Preferred planning posture

If the project wants to close `CDL-050` rather than continue carrying it forward, the next
Treasury window should be a **narrow Treasury ECU-governor and blocker-resolution block**.

The lane should not absorb every long-horizon macroeconomic idea. In particular, the following
should remain out of scope unless separately elevated:
- Jubilee / long-horizon hardness-rotation theory,
- node-rent lifecycle or public-goods fade redesign,
- broad knowledge-graph preservation economics,
- unrelated packaging/bootstrap work,
- consensus runtime follow-on work that does not directly serve Treasury closure.

The correct goal of this window is simpler:
- determine exactly what `CDL-050` means,
- decide whether the L1/L2 prerequisite is real,
- pre-register the evidence program,
- generate discriminating simulation evidence,
- and either open/prelock/ratify `CDL-050` or stop cleanly at the blocker-clearance gate.

## 3. Hard closure gates for CDL-050

The window should be organized around the following gates. `CDL-050` does not open unless all
gates through Gate 7 are satisfied.

### Gate 1 — Lane identity freeze

The project must explicitly decide one of:
- `CDL-050` remains the Treasury lane and is reframed in place around ECU-side governance, or
- `CDL-050` remains narrow and a new CDL carries the broader ECU-governor model.

No blocker can be treated as closed until this is frozen.

### Gate 2 — Architectural prerequisite disposition

The project must explicitly decide one of:
- adopt L1/L2 separation and elevate the Sequestered Financial Shard boundary as a real Treasury
  prerequisite, or
- reject it as a prerequisite and enlarge the Treasury risk model accordingly.

No hidden or assumed prerequisite is allowed.

### Gate 3 — Objective-function and observables freeze

Treasury must have a fixed optimization target before simulations run. The candidate minimum metric
set is:
- `P_e` clamp-respect rate,
- organic ECU production rate,
- productive backlog / queue-clearance behavior,
- release-shock amplitude after time-lock expiry,
- intervention duration and intervention cost.

### Gate 4 — Simulation-method freeze

The simulation brief must be pre-registered before execution:
- scenario matrix,
- parameter families,
- seeds / manifests,
- success criteria,
- discriminating thresholds,
- tie-break logic for ambiguous outcomes.

### Gate 5 — Blocker 1 closure

The recovery rule closes only if:
- trigger and recovery use different observables,
- the Treasury cannot satisfy its own exit condition through direct intervention output,
- multiple candidate recovery rules are compared,
- false-exit and late-exit behavior are measured under adversarial scenarios.

### Gate 6 — Blocker 2 closure

The risk-tolerance judgment closes only if:
- every ECU-side lever has an explicit ceiling,
- no uncapped lever remains,
- categorical prohibitions are explicit,
- worst-case intervention cost is bounded from simulation evidence.

### Gate 7 — Blocker 3 closure

Discriminating evidence exists only if:
- leading candidate choices are materially separated on the pre-registered metrics,
- not merely directionally preferred,
- and not statistically or operationally ambiguous.

If the evidence is weakly differentiated again, blocker 3 remains open.

### Gate 8 — Opening / prelock / ratification authorization

Only if Gates 1-7 pass may the lane advance into opening, prelock hardening, and ratification.

## 5. Phase-by-phase scope

### Phase 450 — Sequence lock + lane-identity freeze

Purpose:
- open the Treasury closure block as a dedicated window,
- freeze whether `CDL-050` is being reframed in place or whether a new CDL is required,
- freeze non-goals so the lane cannot absorb Jubilee and unrelated macro work.

Output target:
- a post-`449` sequence-lock artifact that states exactly what this window is trying to close.

### Phase 451 — Treasury objective-function and observables contract

Purpose:
- define what Treasury is optimizing,
- define the observables that later simulations must report,
- prevent post hoc metric shopping.

Output target:
- a Treasury measurement contract and evidence-source ladder specific to the lane.

### Phase 452 — L1/L2 prerequisite disposition and interface boundary

Purpose:
- formalize the Sequestered Financial Shard question,
- either adopt it as a Treasury prerequisite or reject it explicitly,
- define the boundary conditions the risk model must respect.

Output target:
- one auditable architecture artifact stating whether L1/L2 separation is required, optional, or
  rejected for `CDL-050`.

### Phase 453 — SIM-T commission brief and measurement contract

Purpose:
- pre-register all simulation scenarios,
- define parameter families and discriminating criteria,
- lock manifests, seeds, and result expectations before any run begins.

Output target:
- a formal Treasury adversarial commission brief.

### Phase 454 — SIM-T execution I

Purpose:
- run the scenario families,
- capture manifests and raw outputs,
- ensure evidence is reproducible and replayable.

Output target:
- the first Treasury evidence package.

### Phase 455 — SIM-T execution II + comparative synthesis

Purpose:
- compare candidate recovery rules and lever ceilings,
- determine whether the evidence actually discriminates,
- rank candidate parameter families.

Output target:
- a comparative synthesis artifact, not just raw tables.

### Phase 456 — Blocker-clearance gate

Purpose:
- answer explicitly whether blocker 1, blocker 2, and blocker 3 are cleared,
- answer explicitly whether the L1/L2 prerequisite is satisfied or rejected,
- stop the lane cleanly if the evidence is still ambiguous.

Hard rule:
- no `CDL-050` opening if Phase `456` does not publish a clean pass on all required gates.

### Phase 457 — `CDL-050` opening

Purpose:
- open the constitutional row only after the blocker-clearance gate passes,
- preserve exact scope and non-goals,
- keep the opening additive only.

### Phase 458 — `CDL-050` prelock hardening and adversarial review

Purpose:
- harden language,
- freeze the selected recovery criterion and risk ceilings,
- adversarially review the evidence bundle before ratification.

### Phase 459 — `CDL-050` ratification

Purpose:
- ratify the Treasury lane only if the opening and prelock phases remain clean,
- lock the constitutional contract actually supported by the evidence program.

Note:
- this candidate window ends on ratification rather than on a separate closure gate; if the lane
  needs a coherence or handoff artifact immediately after ratification, that should be planned as
  the next sequence step rather than silently folded into Phase `459`.

## 6. Evidence discipline for the window

The evidence base for this window should follow these rules:
- primary sources first: active constitutional artifacts, active ADRs/specs, simulation manifests,
  raw run outputs, synthesis artifacts,
- research notes and reconstructed chat materials remain hypothesis inputs only,
- no blocker closes on prose alone,
- no parameter locks without pre-registered discriminating metrics,
- no retroactive rewriting of earlier constitutional language during the window,
- ambiguous simulation outcomes preserve the blocker rather than forcing closure.

---

## 7. Non-goals and failure path

Non-goals for this candidate window:
- no Jubilee or long-horizon token-rotation ratification,
- no knowledge-node rent or preservation-logic redesign,
- no packaging/bootstrap work,
- no unrelated consensus runtime work,
- no forced opening of `CDL-050` if the evidence remains ambiguous.

Failure path:
- if Phase `456` does not clear the blockers decisively, the correct constitutional result is
  carry-forward with a clearer blocker memo, not a rushed opening.
