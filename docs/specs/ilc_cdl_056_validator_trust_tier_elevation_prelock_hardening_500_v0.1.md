## 2. Tiebreaker design boundary

The tiebreaker rule is bounded to consensus-related disputes only. It is not an extra panel seat,
not a weighted quorum expansion, and not a quorum-ladder redesign.

## 3. Liveness-threshold coupling

Trust-tier eligibility and revocation remain coupled to the ratified CDL-055 liveness threshold.
CDL-056 does not recalibrate that threshold and does not create a second validator-performance
metric.

## 4. Rejected alternatives

Rejected in prelock hardening:
- inheritable trust-tier status,
- permanent trust-tier privilege after validator inactivity,
- automatic quorum weighting beyond the existing 7+1 structure,
- using ADM-001 as a substitute for constitutional ratification.
